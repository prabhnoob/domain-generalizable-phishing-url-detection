# Proposal submission package

Main source: `01_Proposal.tex`

Before submission, replace every bracketed placeholder in the author block and
the repository URL. Keep the graduate student last in the author list. Rename
the final ZIP to `1_Proposal_firstname1_firstname2_[...].zip` using the team
members' first names.

Compile with an ACM-compatible LaTeX installation, for example:

```text
latexmk -pdf 01_Proposal.tex
```

The included PDF was compiled with Tectonic using the ACM `sigconf` class.
